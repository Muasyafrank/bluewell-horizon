# Order quotations

After a customer places an order, the admin can open it (the invoice icon in the Orders tab, or "Prepare quotation" in the order view), price each item, choose the payment methods to offer, preview the email and send it. The customer receives a quotation with the items, totals, validity date and payment details, using the order number as the payment reference, and the company gets a copy. Sending moves the order to a new **Quoted** status and stores the agreed figures on the order. Totals are always recomputed on the server. New: `routers/quotations.py`, `core/quotation.py`, `core/payments.py`, `models/quotation.py` (new `quotations` table, created automatically on start), `features/admin/panels/QuotationModal.jsx`. Payment details come from the new `PAYMENT_*` settings in `.env` (see `.env.example`); a method with no details is not offered.
